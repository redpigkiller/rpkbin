# mcucc 變更紀錄

目前為 **beta**。以下版本標記描述編譯器契約的演進。套件發行版號另由發行環境決定。

| 版本 | 使用者可見的變更 |
|---|---|
| v7.4 | 載入 Target 時驗證載入／儲存的位址種類。編碼長度與宣告不符時，編譯、組譯及差異驗證回報含 form id 和兩個長度的 `TargetError`。文件釐清取樣、私有槽、分支、編碼器和 ABI 契約。 |
| v7.3 | 補齊操作指南、AI 指南、語言與 Target 參考、錯誤目錄及可重現範例。 |
| v7.2 | 新增 `park_policy` 與 `--park-policy`。可選最小輸出、優先堆疊或優先原配置。 |
| v7.1 | 堆疊預算按實際呼叫點計算；位元組數相同時優先沿用原配置。 |
| v7.0 | 新增堆疊暫存預算，可為不使用某個值的區間成對保存／還原。正深度報告增加 `parks`、`push_depth`。 |
| v6.0 | 配置失敗時可依專用 pool 契約重試。報告標記成功的私有槽重試，差異測試拒絕來源存取 pool。 |
| v5.2 | 增補高位元邊界和條件式比較的驗證案例，保留既有成功輸出。 |
| v5.1 | 比較旗標的適用條件、取樣與加寬規則更明確。 |
| v5.0 | 支援最高位元為零時才可靠的無號比較旗標，以及可以從非零位址開始的具名取樣窗口。 |
| v4.3 | 擴充來源值與機器值對照，補齊暫存器保存與分支的驗證。 |
| v4.2 | 依 form 的絕對／相對範圍取樣跳躍與呼叫。CLI 顯示呼叫及回傳測試的兩種略過計數。 |
| v4.1 | 依宣告及被呼叫函式的結果，獨立檢查呼叫對暫存器的影響。 |
| v4.0 | 強化 form、旗標、控制流程與試跑結果的核對。 |
| v3.9 | 擴充運算元互異的取樣，以及可到達的回傳出口檢查。 |
| v3.8 | 拒絕區域名稱遮蔽模組名稱及組語符號衝突，擴充搬移和載入的檢查。 |
| v3.7 | 記憶體擴充指派的位址只求值一次，並增強分支與寫入狀態檢查。 |
| v3.6 | `verify --window` 改為明定取樣範圍，其他取樣參數提供清楚的預設值。 |
| v3.5 | 內嵌組語可輸出文字，報告標示未做機器差異測試；機器碼組譯拒絕該片段。 |
| v3.4 | 來源參考執行檢查可由來源與位址寬度決定的規則，目標相容性由編譯檢查。 |
| v3.3 | 補足宣告及測試的邊界規則。 |
| v3.2 | 補足支援形式、分支與驗證規則。 |
| v3.1 | 增補組語輸出與目標描述細節。 |
| v3 | 建立受限 Python、可重定目標描述、編譯輸出與驗證流程。 |
